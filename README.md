一个可以让你更丝滑地观看神秘小动画，也可以丝滑地多档变速的播放器！

只需按照
CustomVideos
-VideoSet1(名字随意)
--Vloop1.mp4
--Vloop2.mp4
--Vloop3.mp4
--Vloop4.mp4
--Vloop5.mp4
--VFinal.mp4
-VideoSet2
--... ...

的方式放置首尾循环的视频即可愉快使用。其中VideoSet文件夹的名字随意，CustomVideos文件夹的名字不可更替，Vloop和VFinal的名字也不可更替

我还提供了一个可以自动剪辑出一段视频中首尾相接的片段的功能，只需在程序主界面点击Auto Cutter即可进入，其中有使用说明
